# Security Policy

## Supported Versions

Security fixes are applied to the latest minor release line. Older lines do not
receive backports.

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests.**

Report them privately using one of these channels:

1. [Open a private security advisory](https://github.com/cocosmos/filament-sticky-save-bar/security/advisories/new)
   on GitHub (preferred).
2. Email **contact@mipam.ch** with the subject line
   `SECURITY: filament-sticky-save-bar`.

Please include as much of the following as you can:

- The type of issue and the affected component or file.
- The package version, plus the Filament, Laravel, and PHP versions in use.
- Step-by-step instructions to reproduce the issue.
- Proof-of-concept code, if available.
- The impact you believe the issue has.

## What to Expect

- **Acknowledgement** within 5 business days.
- **Assessment and severity triage** within 10 business days, including whether
  the report is accepted.
- **Fix and release** for accepted reports as soon as practical, with the
  timeline driven by severity. You will be kept up to date on progress.
- **Disclosure** coordinated with you. A GitHub security advisory is published
  once a fix is available, and you will be credited unless you ask otherwise.

If a report is declined, you will get an explanation of why.

## Scope

This policy covers the code in this repository — the
`cocosmos/filament-sticky-save-bar` Composer package. Vulnerabilities in
Filament, Laravel, or other dependencies should be reported to those projects
directly.

Thank you for helping keep this package and its users safe.
